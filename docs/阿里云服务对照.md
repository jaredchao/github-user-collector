# 本作业 AWS 服务 → 阿里云对照清单

按项目实际用到的服务整理。两个**同名陷阱**先记住：**阿里云 ECS = AWS EC2（虚拟机）**，不是 AWS 的容器服务 ECS；**阿里云 ALB** 才是 AWS ALB 的对应物（老产品叫 SLB/CLB）。

## 网络层

| AWS（本作业用法） | 阿里云对应 | 备注 |
|---|---|---|
| VPC | 专有网络 VPC | 概念几乎一致 |
| Subnet（公有/私有子网） | 交换机 vSwitch | 阿里云的"子网"叫交换机，同样绑定可用区 |
| Internet Gateway | （无独立产品） | 阿里云 VPC 公网能力靠 EIP，没有单独的 IGW 资源 |
| NAT Gateway | NAT 网关 | 同样按小时+流量计费，同样"闲着也收钱" |
| Route Table | 路由表 | 一致 |
| Security Group | 安全组 | 一致，也支持安全组互相引用 |
| Elastic IP | 弹性公网 IP（EIP） | 一致 |

## 计算与容器

| AWS | 阿里云对应 | 备注 |
|---|---|---|
| EC2（跳板机） | ECS 云服务器 | ⚠️ 阿里云 ECS = AWS EC2，与 AWS 容器服务 ECS 无关 |
| SSM Session Manager | 云助手 + 会话管理 | 同样免公网 IP、免 SSH 密钥登录 |
| Lambda | 函数计算 FC | 同样按调用计费、支持容器镜像、VPC 接入 |
| ECS（容器编排） | ACK（容器服务 K8s）或 SAE | 阿里云没有"非 K8s 的托管编排"；最像 ECS+Fargate 体验的是 SAE（给镜像就跑，免管节点） |
| Fargate（无服务器容器运行时） | ECI（弹性容器实例） | ACK Serverless 底层就是 ECI |
| ECR | ACR（容器镜像服务） | 一致，分个人版/企业版 |

## 流量入口与服务发现

| AWS | 阿里云对应 | 备注 |
|---|---|---|
| ALB（host 分流、目标组） | ALB（应用型负载均衡） | 转发规则/服务器组概念对得上 |
| API Gateway | API 网关 | 一致 |
| ACM 证书 | 数字证书管理服务 | 通配符证书一般收费，不如 ACM 大方 |
| Cloud Map DNS 型（`zuoye.internal`） | PrivateZone（私网 DNS） | VPC 内私有域名解析，几乎一对一 |
| Cloud Map API 型（`zuoye.api`，DiscoverInstances） | MSE Nacos（注册中心） | 注册元数据 + API 查询的玩法同构；Nacos 本就是阿里开源 |

## 数据与存储

| AWS | 阿里云对应 | 备注 |
|---|---|---|
| RDS PostgreSQL | RDS PostgreSQL | 连名字都一样 |
| S3（构建源码桶） | OSS（对象存储） | 一致，也有生命周期规则 |
| CloudWatch Logs | SLS（日志服务） | SLS 的查询/投递能力更强 |

## CI/CD 与身份

| AWS | 阿里云对应 | 备注 |
|---|---|---|
| CodeBuild | 云效 Flow 流水线（构建节点） | 没有独立的"托管构建机"产品 |
| CloudFormation / SAM | ROS（资源编排）/ Serverless Devs | ROS 模板语法致敬 CFN；函数计算的 SAM 等价物是 Serverless Devs（s.yaml） |
| IAM 用户/角色/策略 | RAM（访问控制） | 概念一一对应 |
| IAM OIDC 身份提供商（GitHub Actions 免密钥） | RAM OIDC 身份提供商 | GitHub Actions 同样可 OIDC 换 STS 临时凭证 |
| STS | STS | 同名同用途 |
| Service Quotas（新账号配额坑） | 配额中心 | 新账号限制两边都有 |
| Secrets Manager | KMS 凭据管家 | 一致 |

## 总结

- 网络层和数据库几乎是逐字翻译。
- 最大观念差异在**容器编排**：AWS 有 ECS 这个"轻量非 K8s"选项，阿里云直接是 K8s（ACK）或更高抽象的 SAE。
- **服务发现**：AWS 用 Cloud Map 一个产品覆盖 DNS 型与 API 型；阿里云拆成 PrivateZone（DNS）+ Nacos（注册中心）两个产品。
